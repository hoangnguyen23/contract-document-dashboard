# Original CONTRACT signing

Canonical A/B1.2.0 adapter for list/create/get/command SigningPacket. CHANGE remains explicitly unavailable. Inputs and file digests are immutable; assessments are append-only and independent. Exact artifact and signed-copy byte identity, source ancestry, current scope, cumulative source/upload contributors, per-party action-time authority and on-time readiness are enforced. The implementation does not certify legal effectiveness or cryptographic signatures.

Signed-copy EvidenceCheck PASS records the human comparison against the exact artifact. AUTHORITY_CURRENT PASS evidence covers both authority sources/check files, while SERVICE_READINESS supplies explicit external account/service confirmation. Applicable prior conditions cannot disappear; optional legal conditions are not invented. Historical valid signing is evaluated at its reported instant, not today's authority expiry.

See `docs/plan/signing-implementation.md` for transaction/lock order, FE impact, dependency boundaries and evidence limitations. No automated tests, HTTP workflows or runtime business scenarios were executed.
