# Incident ownership

IncidentService owns immutable original SOURCE, VERIFICATION, RESOLUTION_CANDIDATE, RESOLUTION_ACCEPTED and CLOSE events in cg_g5_event. It calls the obligation-owned remediation factory once under Contract serialization. Received/external due timestamps never reset on new evidence or assessment. No delete/refund/provider execution or allegation-of-guilt action exists.

See ../obligation/README.md for shared evidence, locking, commands, actual Control dependencies and the source/build/acceptance boundary.
