## Frame construction for each workbench

Designer creates defaultlist, emptyfilter, detailsuccess, onepermissionblocked and onebusinessblocked frame. Add all exceptionframes listed above using reusable variants; severe mutually exclusive states need separateframes, not one ambiguousscreen. Every primarymutation includes before/dialog/pending/success/error sequence and correctresourceversion context. Mobile detailsretaincriticalfacts/actions. Each frameannotates operationID, responsefieldpath, requiredgrant/hint, refreshdependencies and errorcodes from canonicalreference.

## Dependency order

F2 Policy/Admin can start after sharedshell/protocol; Policy must exist for real approval integration. F3 originalContract/signing relies on F1 review and jobs/files. F4 needs F3versions/effectivity and Noticecomponents. F5 needs F4source/versions/notices plus shared evidence; F6 needs all recordparentlinks, privatefiles and holds. Design can proceed ahead at fixedcontract; real integration cannot claim predecessor accepted without evidence. Earlier owner allowed BEbreadth before FE; that does not waive ultimate A§14 gates.

## UI transformations with explicit responsibility

Money display may group digits and append ₫ while rawpayload stays decimalstring. Date display DD/MM/YYYY must roundtrip YYYY-MM-DD without UTCconversion. Timestamp display states timezoneAsia/Ho_Chi_Minh; canonicalpayload UTCmillisecondstaysunchanged. Null, absentproperty and emptystring are distinct. ID is not primaryhumanlabel if accessiblelabel exists; never guess names for inaccessibleactors. Render text safely, no HTMLfromreason/filename; URLs/downloads only canonicalauthorizedpaths. Sorting/filtering/pagination reflectserverallowlist, not UI-librarydefaults.
